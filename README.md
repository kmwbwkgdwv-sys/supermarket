# 🛒 マートメイツ（MART MATES）

みんなでスーパーを経営する 3D 協力ゲームです。商品を棚に並べて、レジでお会計をして、スキルボードでお店をどんどん大きくしていきます。
ブラウザだけで動くので、GitHub Pages に置くだけでスマホでも PC でも遊べます。

> 「Supermarket Together」のような遊び方を参考にしたオリジナル作品です。公式作品・開発元とは関係ありません。キャラクター・ロゴ・店名などはすべてオリジナルです。

## 🎮 操作

| | スマホ | PC |
|---|---|---|
| 移動 | 左のスティック | WASD / 矢印キー |
| 視点 | 画面右側をドラッグ | マウス（画面クリックでロック） |
| 行動（拾う・補充・値段など） | オレンジの大きいボタン | E / 左クリック |
| 段ボールを開ける／閉じる | 📦 ボタン | F |
| サブ行動（置く・回収・回転など） | 小さいボタン | Q / 右クリック |
| ジャンプ / ダッシュ | ⤒ / 🏃 | Space / Shift |
| 建築モード | 🔨 | B |
| 視点切替 | 🎥 | V |
| チャット（ルームのみ） | 💬 | Enter |
| メニュー | ≡ | Esc |

**基本の流れ**：最初は棚も倉庫も空っぽ。マネージャーボードで発注 → 倉庫の在庫棚（または店の前の荷物置き場）から段ボールを拾う → 「開ける」→ 売り場の棚を狙って「補充」→ **入口の看板を OPEN に** → レジに入ってスキャン＆お会計 → 22時に閉店して収支画面 →「次の日へ」→ レベルアップでもらえる SP でスキルを解放 → お金がたまったらマネージャー室の拡張ボードで区画を買い足す。空き箱は裏口のリサイクルボックスへ。

## 🚀 GitHub Pages で公開する

スマホのブラウザだけでもできます。

1. [github.com](https://github.com) にログインして、右上の「＋」→ **New repository**。名前（例：`martmates`）を入れて **Public** で作成。
2. 作ったリポジトリで **Add file → Upload files** を押し、この zip を展開した中身（`index.html` / `css` / `js` / `README.md` など）を**フォルダごと**アップロードして **Commit changes**。
   - `index.html` がリポジトリの一番上にある状態にしてください。
3. リポジトリの **Settings → Pages** を開き、**Source: Deploy from a branch**、**Branch: main / (root)** を選んで **Save**。
4. 1〜2分待つと `https://あなたのユーザー名.github.io/martmates/` で遊べます。

> Firebase を設定しなくても「ひとりで経営」は遊べます（データは端末内に保存）。オンライン機能（引き継ぎ・ルーム・チャット・ランキング）を使うには次の設定をしてください。

## 🔥 Firebase の設定（オンライン機能）

> ✅ `js/firebase-config.js` には **supermarket-9acfb** プロジェクトの設定（apiKey と databaseURL）が入っています。
> あとは Firebase コンソールで **下の手順 2（匿名ログインを有効）・4（ルールを公開）・6（承認済みドメインに GitHub Pages を追加）** をすれば、オンライン機能が使えます。

1. [Firebase コンソール](https://console.firebase.google.com/) で **プロジェクトを追加**（Google アナリティクスはオフでOK）。
2. **Authentication → はじめる → Sign-in method → 匿名** を **有効** にする。
3. **Realtime Database → データベースを作成**。場所は好きなところ（例：シンガポール）、**ロックモード** で開始。
4. Realtime Database の **ルール** タブを開き、このリポジトリの `database.rules.json` の中身を丸ごと貼り付けて **公開**。
5. **プロジェクトの設定（⚙）→ マイアプリ → ウェブ（`</>`）** でアプリを登録し、表示された `firebaseConfig` の値を `js/firebase-config.js` にコピー。
   - `databaseURL` が入っているか必ず確認してください（Realtime Database 画面の上部に表示される URL です）。
6. **Authentication → 設定 → 承認済みドメイン** に `あなたのユーザー名.github.io` を追加。
7. 変更した `js/firebase-config.js` を GitHub にアップロード（上書き）すれば完成です。

`firebaseConfig` の値はウェブアプリでは公開されても問題ない値です。データの保護は `database.rules.json` のルール（ログイン必須・データ形式チェック）で行っています。

### オンライン機能のしくみ
- **引き継ぎコード**：`saves/<コード>` にお店とキャラのデータを保存。起動時にクラウドの方が新しければ自動で取り込みます。
- **ルーム**：最初に入った人（ホスト）の端末でお客さんや従業員の動きを計算し、他の人はその結果を受け取って表示します。ホストが抜けるとルームは解散します。
- **みんなの店**：ルームのお店はルームIDごとに `shops/<ルームID>` に保存されます（ホストの端末が約30秒ごと・閉店時・退出時に保存）。次に同じIDで集まれば、**誰がホストになっても続きから**遊べます。はじめてのIDでは、ホストが「自分のお店のデータで始める」か「新しいお店で始める」かを選びます。ひとりで遊ぶ自分のお店のデータは、**ほかの人のルームに参加しても、自分でルームを作っても変わりません**（「自分のお店をコピーして始める」はコピーを使う）。誰もいないIDに先に着いたときは「やめる」で戻れます。端末の容量がいっぱいのときは、古いルームの控えから消して自分のお店の保存を優先します。ルーム画面に前に遊んだルームが出ます。
- **ルールの更新**：みんなの店を保存するため、`database.rules.json` に `shops` を追加しました。Firebase コンソールの Realtime Database → ルール に貼り直して公開してください。
- **以前のセーブ**：売り場を奥にも広げられるようにしたとき（セーブ v8）、倉庫・マネージャー室とそこに置いた物・段ボールは自動で10m奥へ引っ越し、倉庫へつながる真ん中の奥の4区画が無料で追加されます。倉庫を奥にも広げられるようにしたとき（セーブ v9）は、マネージャー室・搬入口・奥の壁ぎわの物がさらに8m奥へ引っ越し、真ん中の奥の倉庫（倉庫C奥）が無料で追加されます。
- **ランキング**：`lb/<プレイヤーID>` に店レベル・総売上・プレイ時間を記録します。

## 🎵 BGM について
- BGM は端末の中で**自動作曲して生成**しています（6曲：ポップ／Lo-Fi／ボサノバ／8ビット／ジャズ／ファンク）。初回だけ数秒かかり、その後は端末に保存されます。
- 設定の「📁 端末の曲を選ぶ」で自分の音楽ファイルを BGM にできます。
- BGM と効果音は同じしくみで鳴らしているので、**いっしょに鳴ります**。ふだんはゲームの中だけで鳴り、iPhone の **ダイナミックアイランドやロック画面には表示されません**。
- アプリを閉じたり画面をロックしたりすると BGM と効果音は止まり、戻ると続きから流れます（バックグラウンドでは再生しません）。
- **Spotify などを聴きながら遊べます**：設定の「音の鳴らし方」が「🎧 ほかのアプリと一緒に」（ふつう）なら、ほかのアプリの音楽を止めずにゲームの音もいっしょに鳴ります。「🎧 Spotifyを聴きながら遊ぶ」ボタンで BGM を止めて効果音だけにできます。
- iPhone では仕組み上、「ほかのアプリと一緒に鳴らす」と「マナーモードでも鳴らす」は同時にできません。一緒に鳴らすときはマナーモード（消音）を切るとゲームの音が聞こえます。「🔔 マナーモードでも鳴らす」にすると、ほかのアプリの音楽は止まります。
- iPhone では音量スライダーが効かないことがあります。本体の音量ボタンで調整してください。

## 🖥 画質と動作の重さ
- **最高画質**：PCや高性能スマホ向け。PC（8コア以上）では最初からオンです。
- 重いときは **最高画質をオフ** → **影をオフ** → **描画解像度を下げる** → **軽量化モード**（自動で再読み込み）の順に試してください。性能の低い端末では最初から軽量寄りの設定になります。
- 以前のバージョンのセーブは新しい店舗レイアウトに自動で引っ越します（置いていた設備の代金は全額返金、棚の商品は箱に戻ります）。

## 📁 ファイル構成

```
index.html              入口（three.js は CDN から読み込み）
css/style.css           画面デザイン
js/main.js              起動・画面遷移・メインループ
js/game.js              ゲーム中の操作・同期・描画のつなぎ
js/sim.js               経営シミュレーション（お客さん・従業員・レジ・1日の流れ）
js/nav.js               お客さん・従業員の経路探索（A*）
js/data.js              商品・設備・スキルなどのデータ
js/render.js            3D描画（棚の商品はインスタンス描画で軽量化）
js/models/*.js          商品・設備・建物・キャラクターの3Dモデル
js/textures.js          ラベルや看板などの絵（Canvasで生成）
js/audio.js             BGMの自動作曲と効果音
js/input.js             タッチ・キーボード・マウス操作、ボタン配置編集
js/net.js               Firebase（引き継ぎ・ルーム・チャット・ランキング）
js/save.js              セーブデータ・引き継ぎコード
js/ui.js, js/gameui.js  各画面とゲーム中のUI
js/firebase-config.js   ← ここに自分の Firebase 設定を入れる
database.rules.json     Realtime Database のルール
```

ビルド不要の素の JavaScript（ES モジュール）です。ローカルで試すときは `python3 -m http.server` などでフォルダを配信して `http://localhost:8000` を開いてください（ファイルを直接開くと動きません）。
